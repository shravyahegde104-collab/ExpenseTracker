# Expense Tracker

A simple Java-based expense tracking application.

## Features

- Add expenses
- View expenses
- Store expenses in a CSV file
- Calculate total expenses
- Menu-based console interface

## Technologies Used

- Java
- CSV
- Git
- GitHub

ExpenseTracker/

## How to Run

1. Open the project in VS Code.
2. Open the terminal in the project folder.
3. Compile the Java files.
4. Run the `Main` class.
